# Saturation Homebrew Tap

Official Homebrew formulae for Saturation developer tools.

## Install the Saturation CLI

```console
brew install Saturation-IO/tap/saturation
```

Homebrew adds this tap automatically. You can also add it first:

```console
brew tap Saturation-IO/tap
brew install saturation
```

## Update

```console
brew update
brew upgrade saturation
```

## Documentation

See the [Saturation CLI repository](https://github.com/Saturation-IO/saturation-cli)
for authentication, commands, release checksums, and other installation methods.

Report CLI problems in the
[Saturation CLI issue tracker](https://github.com/Saturation-IO/saturation-cli/issues).

Formulae in this repository are updated by the corresponding GitHub release
workflow. Each formula downloads binaries from a public Saturation repository.
